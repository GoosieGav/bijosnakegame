# Bijo Snake Game

A fun snake game featuring Bijo as the snake head collecting dumplings!

## Features

- **Bijo Character**: The snake head is Bijo, with different sprites for each direction
- **Dumpling Collection**: Collect regular and special golden dumplings
- **Beautiful Graphics**: Colorful visuals with gradient effects
- **Scoring System**: Earn points for each dumpling collected
- **Pause Functionality**: Press P to pause/resume the game

## How to Play

1. Install pygame: `pip install -r requirements.txt`
2. Run the game: `python bijo_snake_game.py`
3. Use arrow keys to move Bijo around
4. Collect dumplings to grow longer and increase your score
5. Avoid hitting walls or yourself
6. Press P to pause/unpause the game
7. Press SPACE to restart after game over

## Controls

- **Arrow Keys**: Move Bijo in different directions
- **P**: Pause/Resume the game
- **SPACE**: Restart after game over
- **ESC/Close Window**: Quit the game

## Scoring

- Regular dumpling: 10 points
- Special golden dumpling: 50 points

Enjoy playing with Bijo!
